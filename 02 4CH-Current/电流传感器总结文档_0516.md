## 一、项目概述

### 1.1 项目简介

4CH-Current 是一个**4通道电流传感器**项目，用于实时监测4路电流信号。该项目包含完整的软硬件解决方案，适用于工业监控、电机控制、电池管理等应用场景。

### 1.2 硬件信息

| 组件 | 型号/规格 |
|------|-----------|
| **主控芯片** | STM32F103C8T6 (Cortex-M3) |
| **电流传感器** | INA282 高侧电流放大器 |
| **显示屏** | OLED (I2C接口) |
| **通信接口** | UART (USART1/USART2) |
| **ADC** | 12位ADC，支持DMA连续采集 |
| **通道数** | 4通道 (PA0/PA1/PA4/PA5) |

### 1.3 软件架构

项目采用**三层架构**设计：

## 二、功能模块详解

### 2.1 固件模块

#### 2.1.1 ADC 数据采集

- **采集方式**：DMA连续采集，支持4通道同时采样
- **采样精度**：12位ADC，参考电压3.3V
- **数据流程**：
  ```
  ADC (DMA) → 原始缓冲区 → process_adc_data() → 滤波器 → g_current_values[]
  ```

#### 2.1.2 电流计算

采用 **INA282** 放大器的计算公式：
```
电流 = (Vout - Vref) / (Gain × Rshunt)
```

其中：
- `Vout`：ADC采样电压
- `Vref`：参考电压
- `Gain`：INA282增益 (50V/V)
- `Rshunt`：采样电阻值

#### 2.1.3 数字滤波

支持多种滤波算法：
- **滑动平均滤波**：窗口大小可配置
- **EMA指数滤波**：alpha系数可调
- **校准补偿**：每通道独立的gain和offset参数

#### 2.1.4 UART 通信协议

支持两种协议模式：

| 模式 | 格式 | 说明 |
|------|------|------|
| **二进制协议** | `AA 55 | CMD | LEN | DATA | CRC | 0D 0A` | 自定义协议，支持双向通信 |
| **FireWater协议** | `$CURRENT,ch0,ch1,ch2*XX\r\n` | 文本格式，兼容VOFA+ |

#### 2.1.5 OLED 显示

- 实时显示4通道电流值
- 更新频率：可配置（默认100ms）
- 显示格式：`M1: 0.12 A`

### 2.2 上位机应用

#### 2.2.1 功能特性

- **实时数据可视化**：4通道电流曲线图
- **串口自动扫描**：自动检测可用串口
- **CSV数据记录**：支持数据导出
- **设备控制**：版本查询、设备重置

#### 2.2.2 技术栈

| 组件 | 技术 |
|------|------|
| **GUI框架** | PySide6 (Qt for Python) |
| **图表库** | pyqtgraph |
| **串口通信** | pyserial |
| **包管理** | UV |

#### 2.2.3 使用流程

1. 连接设备（选择串口、点击连接）
2. 查看实时数据（曲线图自动更新）
3. 记录数据（点击开始记录）
4. 导出CSV文件

### 2.3 ROS 集成

#### 2.3.1 包信息

- **包名**：`ch4_current_sensor`
- **ROS版本**：ROS Noetic
- **依赖**：Python 3.8+, pyserial

#### 2.3.2 话题发布

| 话题 | 消息类型 | 说明 |
|------|----------|------|
| `/current_data` | `CurrentData` | 电流数据 |
| `/diagnostics` | `DiagnosticArray` | 诊断信息 |

#### 2.3.3 消息定义

```msg
Header header
float32 ch0_current  # 通道0电流 (A)
float32 ch1_current  # 通道1电流 (A)
float32 ch2_current  # 通道2电流 (A)
float32 ch3_current  # 通道3电流 (A)
uint16 ch0_raw_adc   # 通道0原始ADC值
uint16 ch1_raw_adc   # 通道1原始ADC值
uint16 ch2_raw_adc   # 通道2原始ADC值
uint16 ch3_raw_adc   # 通道3原始ADC值
```

### 2.4 校准工具

#### 2.4.1 功能概述

- **图形化界面**：基于tkinter的GUI
- **实时数据显示**：4通道电流实时刷新
- **自动数据采集**：每点采集20个样本取平均
- **线性回归拟合**：自动计算GAIN和OFFSET参数
- **结果可视化**：显示校准曲线和R²值

#### 2.4.2 校准公式

```
真实电流 = 测量电流 × GAIN + OFFSET
```

- **GAIN**：校正比例误差（理想值1.0）
- **OFFSET**：校正零点漂移（理想值0.0）

#### 2.4.3 使用流程

1. 连接设备
2. 选择要校准的通道
3. 施加已知电流，采集校准点
4. 计算校准参数
5. 复制C代码到固件

## 四、构建与运行

### 4.1 固件构建

```bash
# 使用Keil MDK-ARM打开工程
Firmware/MDK-ARM/4CH-Current.uvprojx

# 或使用STM32CubeMX配置
Firmware/4CH-Current.ioc
```

### 4.2 上位机运行

```bash
cd HostApp
uv sync                    # 安装依赖
uv run ch4-current         # 运行应用
```

### 4.3 ROS节点运行

```bash
cd ~/catkin_ws && catkin_make
roslaunch ch4_current_sensor sensor.launch port:=/dev/ttyUSB0 baudrate:=115200
```

## 六、技术特点

1. **高精度采集**：12位ADC + DMA连续采样
2. **多通道支持**：4通道独立监测
3. **实时滤波**：支持滑动平均和EMA滤波
4. **灵活通信**：支持二进制和文本两种协议
5. **跨平台**：支持Windows/Linux/macOS
6. **ROS集成**：可直接用于机器人系统
7. **校准工具**：提供图形化校准界面
