# 4通道电流传感器校准工具使用指南

## 📋 功能概述

`calibration_tool.py` 是一个基于 **tkinter** 的图形化校准工具，功能包括：

✅ **图形化界面** - 无需命令行操作，界面友好  
✅ **实时数据显示** - 4通道电流数据实时刷新  
✅ **灵活通道选择** - 勾选需要校准的通道，支持单通道或多通道校准  
✅ **自动数据采集** - 每个点自动采集20个样本并取平均值  
✅ **线性回归拟合** - 自动计算最佳 GAIN 和 OFFSET 参数  
✅ **结果可视化** - 显示校准曲线和拟合优度（R²）  
✅ **一键复制** - C代码直接复制到剪贴板  

## 📦 依赖库安装

## 🚀 快速开始

### 1. 启动工具

```bash
python calibration_tool.py
```

程序会打开图形化界面。

### 2. 连接设备

1. 在"串口连接"区域，点击 **刷新** 按钮查看可用串口
2. 从下拉列表中选择正确的串口（通常是 USB-SERIAL CH340）
3. 点击 **连接** 按钮
4. 连接成功后，状态指示灯变为绿色 ● **已连接**

### 3. 查看实时数据

连接后，4个通道的电流数据会实时更新显示：

```
□ 通道0 (PA0/M1)    0.123 A
□ 通道1 (PA1/M2)    0.045 A  
□ 通道2 (PA4/M3)    0.000 A
□ 通道3 (PA5/M4)    0.087 A
```

### 4. 选择要校准的通道

**勾选**你想要校准的通道前面的复选框。例如：

- 只用通道0和通道1 → 只勾选这两个
- 使用所有通道 → 全部勾选

### 5. 采集校准数据

对于每个校准点：

1. **施加已知电流**（使用可调电源 + 万用表测量）
2. **在"参考电流 (A)"输入框**输入万用表测量的真实值（例如 `1.5`）
3. 点击 **添加校准点** 按钮
4. 等待采集完成（按钮会显示"采集中..."）
5. 采集完成后，数据会显示在下方文本框中

**推荐采集策略：**

| 点编号 | 参考电流 (A) | 说明 |
|--------|-------------|------|
| 1      | 0.000       | 零点（用于校准偏移） |
| 2      | 0.500       | 低电流点 |
| 3      | 1.000       | 中等电流点 |
| 4      | 2.000       | 高电流点 |
| 5      | 3.000       | 满量程点 |

**最少 2 个点，推荐 5 个点以上。**

### 6. 计算校准参数

采集完成后，点击 **计算参数** 按钮。

程序会：
- 计算每个通道的 GAIN 和 OFFSET
- 显示拟合优度（R²值）
- 自动生成 C 代码

### 7. 复制并应用参数

1. 点击 **复制C代码** 按钮，代码会自动复制到剪贴板
2. 打开 `Firmware/Core/Inc/current_types.h`
3. 找到 L65-L83 的校准参数定义
4. 粘贴新的代码
5. 重新编译并烧录固件

### 8. 查看校准曲线（可选）

点击 **显示曲线** 按钮，会弹出新窗口显示：

- 蓝色散点：实际采集的数据点
- 灰色虚线：理想线（y=x，无需校准）
- 红色实线：拟合线
- R² 值：拟合优度（越接近1越好）

可以点击 **保存图表** 将曲线保存为 PNG 图片。

## 📊 校准原理

### 校准公式

```
真实电流 = 测量电流 × GAIN + OFFSET
```

- **GAIN（增益）**：校正传感器的比例误差（理想值为 1.0）
- **OFFSET（偏移）**：校正零点漂移（理想值为 0.0）

### 线性回归

工具使用**最小二乘法**进行线性回归：

```
给定数据点: (x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)
其中：x = 测量值, y = 参考值

求解: y = m·x + b
最小化: Σ(yᵢ - m·xᵢ - b)²

得到: GAIN = m, OFFSET = b
```

### R² 值（拟合优度）

- **R² > 0.99**：拟合优秀 ✅
- **0.95 < R² < 0.99**：拟合良好 ⚠️
- **R² < 0.95**：拟合较差，建议重新采集 ❌

## 🔍 常见问题

### Q1: 为什么需要校准？

**A:** 由于元器件误差、温漂、PCB 布线等因素，传感器的测量值可能偏离真实值。校准可以显著提高精度。

### Q2: 多久需要重新校准？

**A:** 
- **首次使用**：必须校准
- **更换硬件**：需要重新校准
- **长期使用**：每 6-12 个月校准一次
- **环境变化**：温度、供电等环境变化后

### Q3: 采集几个点比较好？

**A:** 
- **最少**：2 个点（不推荐）
- **推荐**：5-10 个点
- **高精度**：10+ 个点，覆盖全量程

### Q4: 只想校准部分通道可以吗？

**A:** 可以！只勾选需要校准的通道即可。未勾选的通道会保持默认值 `GAIN=1.0, OFFSET=0.0`。

### Q5: R² 值很低怎么办？

**A:** 可能原因：
1. **数据点太少** → 增加采集点
2. **参考值测量不准** → 使用更精确的万用表
3. **传感器不稳定** → 检查硬件连接
4. **电流波动大** → 增加滤波或等待稳定
5. **非线性误差** → 检查传感器量程

### Q6: 如何验证校准效果？

**A:** 步骤：
1. 应用新参数并重新烧录固件
2. 施加已知电流
3. 对比传感器显示值与万用表读数
4. 误差应 < 1%（优秀）或 < 3%（良好）

### Q7: "采集中..."卡住了怎么办？

**A:** 
- 检查串口数据是否正常
- 断开重连串口
- 重启程序

### Q8: 可以保存校准数据吗？

**A:** 当前版本不支持保存/加载校准数据。建议一次性完成校准。如需中断，请复制文本框中的数据点信息备份。

## 💡 使用技巧

### 1. 零点校准优先

开始校准前，先采集一个 `0.000 A` 的点（断开所有负载）。这会显著改善偏移补偿的准确性。

### 2. 均匀分布采集点

采集点应尽量均匀分布在整个测量范围内，避免集中在某个区间。

### 3. 重复测量验证

对于关键的电流点（如满量程），可以重复采集2-3次，确保数据一致性。

### 4. 批量校准策略

如果有多个传感器需要校准：
- 使用同一套标准电流源
- 记录每个传感器的校准参数
- 建立校准档案

### 5. 环境稳定

校准过程中保持：
- 温度稳定
- 供电稳定
- 负载稳定
- 避免震动和干扰

如有问题，请检查：

1. `uart_protocol.h` 是否设置为 **FireWater 模式** (`UART_PROTOCOL_TYPE = 1`)
2. 串口波特率是否为 **115200**
3. 固件是否正常运行并发送数据
4. Python 依赖库是否正确安装
5. 串口是否被其他程序占用
