## 一、项目概述

### 1.1 项目简介

WHEELTEC 全向轮小车是一个基于 **STM32F4xx** 的智能移动机器人平台，采用 **FreeRTOS** 实时操作系统，支持全向轮和麦克纳姆轮两种运动模式。该项目集成了平衡控制、IMU姿态感知、电机驱动、无线通信等多项核心技术，适用于科研教学、机器人竞赛、智能物流等应用场景。

### 1.2 硬件信息

| 组件 | 型号/规格 |
|------|-----------|
| **主控芯片** | STM32F40_41xxx (Cortex-M4 with FPU) |
| **内存** | ROM: 512KB, RAM: 128KB |
| **IMU传感器** | MPU6050 (I2C接口，6轴) |
| **电机类型** | 轮毂电机（支持UART和CAN接口） |
| **编码器** | 增量式编码器（TIM2/TIM3/TIM4/TIM5） |
| **遥控器** | PS2手柄支持 |
| **显示屏** | OLED (I2C接口) |
| **调试器** | JLink (8000 kHz) |
| **电池** | 锂电池（支持自动回充） |

## 二、功能模块详解

### 2.1 平衡控制模块

#### 2.1.1 运动学计算

支持两种运动学模式：

**全向轮模式 (Omni)**：
```c
MOTOR_A.Target =  Vy + Omni_turn_radius * Vz;
MOTOR_B.Target = -X_PARAMETER * Vx - Y_PARAMETER * Vy + Omni_turn_radius * Vz;
MOTOR_C.Target = +X_PARAMETER * Vx - Y_PARAMETER * Vy + Omni_turn_radius * Vz;
```

**麦克纳姆轮模式 (Mec)**：
```c
MOTOR_A.Target = +Vy + Vx - Vz * (Wheel_axlespacing + Wheel_spacing);
MOTOR_B.Target = -Vy + Vx - Vz * (Wheel_axlespacing + Wheel_spacing);
MOTOR_C.Target = +Vy + Vx + Vz * (Wheel_axlespacing + Wheel_spacing);
MOTOR_D.Target = -Vy + Vx + Vz * (Wheel_axlespacing + Wheel_spacing);
```

#### 2.1.2 PID 控制算法

采用增量式PI控制器：
```c
int Incremental_PI_A(int Encoder, int Target)
{
    static float Bias, Last_bias;
    Bias = Target - Encoder;
    Motor_A += Velocity_KP * (Bias - Last_bias) + Velocity_KI * Bias;
    Last_bias = Bias;
    return Motor_A;
}
```

#### 2.1.3 速度平滑处理

实现平滑的速度控制，防止突然加减速：
```c
void Smooth_control(float Vx, float Vy, float Vz)
{
    smooth_control.VX += target_limit_float(Vx - smooth_control.VX, -SMOOTH_STEP, SMOOTH_STEP);
    smooth_control.VY += target_limit_float(Vy - smooth_control.VY, -SMOOTH_STEP, SMOOTH_STEP);
    smooth_control.VZ += target_limit_float(Vz - smooth_control.VZ, -SMOOTH_STEP, SMOOTH_STEP);
}
```

### 2.2 IMU 数据处理模块

#### 2.2.1 MPU6050 数据采集

- **采样频率**：100Hz
- **数据类型**：3轴加速度 + 3轴角速度
- **校准机制**：启动前自动采集零偏

#### 2.2.2 卡尔曼滤波器

用于姿态角估计：
```c
void Kalman_Filter(float angle_m, float gyro_m)
{
    // 预测步骤
    angle += (gyro_m - q_bias) * dt;
    P[0][0] += dt * (P[1][1] + P[0][1]) + Q_angle;
    // 更新步骤
    K = P[0][0] / (P[0][0] + R_angle);
    angle += K * (angle_m - angle);
}
```

#### 2.2.3 偏航角处理

- **偏航角归一化**：将角度限制在0-360度范围内
- **零点偏移**：支持手动设置偏航角零点
- **外部航向**：支持外部航向数据输入

### 2.3 电机控制模块

#### 2.3.1 轮毂电机驱动

支持两种通信接口：

| 接口 | 协议 | 说明 |
|------|------|------|
| **UART** | Modbus RTU | 通过USART3通信 |
| **CAN** | CAN 2.0 | 通过CAN1通信 |

#### 2.3.2 编码器反馈

- **编码器类型**：增量式编码器
- **读取频率**：100Hz
- **速度计算**：`RPM = 编码器值 / 缩放因子`

#### 2.3.3 PWM 控制

- **PWM频率**：可配置
- **限幅保护**：最大PWM值16800
- **死区处理**：小角度死区控制

### 2.4 通信接口模块

#### 2.4.1 无线通信

| 通信方式 | 说明 |
|----------|------|
| **PS2手柄** | 支持游戏手柄遥控 |
| **APP控制** | 手机APP蓝牙控制 |
| **航模遥控** | 支持航模遥控器 |
| **CAN总线** | 多机通信 |

#### 2.4.2 数据发送任务

```c
void data_task(void *pvParameters)
{
    while(1)
    {
        // 发送数据到上位机
        CAN_N_Usart_Control();
        vTaskDelay(10);
    }
}
```

### 2.5 自动回充模块

#### 2.5.1 功能概述

- **红外检测**：检测充电底座位置
- **自动对准**：自动调整位置对准充电座
- **充电控制**：监测充电电流和状态
- **状态指示**：RGB灯显示充电状态

#### 2.5.2 充电状态

| 状态 | RGB灯颜色 | 说明 |
|------|-----------|------|
| **普通状态** | 红色 | 正常运行 |
| **开启回充** | 黄色 | 自动回充模式开启 |
| **正在充电** | 紫色 | 正在充电中 |

#### 2.5.3 通信协议

通过CAN总线发送充电状态：
```c
void CAN_Send_AutoRecharge(void)
{
    u8 CAN_SENT[8];
    CAN_SENT[0] = 0;  // 状态标志
    CAN_SENT[1] = ((short)(Red_Docker_X * 1000)) >> 8;
    CAN_SENT[2] = ((short)(Red_Docker_X * 1000));
    // ... 其他数据
    CAN1_Send_Num(0x105, CAN_SENT);
}
```

### 2.6 FreeRTOS 任务管理

#### 2.6.1 任务列表

| 任务名称 | 优先级 | 栈大小 | 功能 |
|----------|--------|--------|------|
| **Balance_task** | 4 | 512 words | 车辆运动控制 |
| **MPU6050_task** | 3 | 256 words | IMU数据读取 |
| **show_task** | 3 | 512 words | OLED显示 |
| **led_task** | 3 | 128 words | LED闪烁 |
| **pstwo_task** | 4 | 256 words | PS2手柄读取 |
| **data_task** | 4 | 512 words | 数据发送 |

#### 2.6.2 任务调度

```c
void start_task(void *pvParameters)
{
    taskENTER_CRITICAL();
    
    xTaskCreate(Balance_task, "Balance_task", BALANCE_STK_SIZE, NULL, BALANCE_TASK_PRIO, NULL);
    xTaskCreate(MPU6050_task, "MPU6050_task", MPU6050_STK_SIZE, NULL, MPU6050_TASK_PRIO, NULL);
    xTaskCreate(show_task, "show_task", SHOW_STK_SIZE, NULL, SHOW_TASK_PRIO, NULL);
    xTaskCreate(led_task, "led_task", LED_STK_SIZE, NULL, LED_TASK_PRIO, NULL);
    xTaskCreate(pstwo_task, "PSTWO_task", PS2_STK_SIZE, NULL, PS2_TASK_PRIO, NULL);
    xTaskCreate(data_task, "DATA_task", DATA_STK_SIZE, NULL, DATA_TASK_PRIO, NULL);
    
    vTaskDelete(StartTask_Handler);
    taskEXIT_CRITICAL();
}
```

## 五、配置说明

### 5.1 车型模式配置

在 `BALANCE/system.h` 中：
```c
#define Omni 1  // 全向轮模式
#define Mec  0  // 麦克纳姆轮模式
```

### 5.2 控制参数配置

```c
#define CONTROL_DELAY  750   // 启动后10秒延迟
#define CAR_NUMBER     7     // 支持的车型数量
```

### 5.3 电机参数配置

```c
typedef struct
{
    float Encoder;       // 编码器值
    float Encoder_Rpm;   // 编码器转速
    float Control_Rpm;   // 控制转速
    float Motor_Pwm;     // 电机PWM
    float Target;        // 目标值
    float Velocity_KP;   // 速度比例系数
    float Velocity_KI;   // 速度积分系数
} Motor_parameter;
```

### 5.4 运动学参数配置

```c
extern float Wheel_perimeter;      // 轮子周长
extern float Wheel_spacing;        // 轮距

extern float Omni_turn_radiaus;    // 转弯半径
```

## 六、技术特点

1. **多任务实时系统**：FreeRTOS确保任务实时性和可靠性
2. **多种运动模式**：支持全向轮和麦克纳姆轮
3. **精确姿态控制**：卡尔曼滤波 + PID控制
4. **多通信接口**：UART、CAN、PS2、APP等多种控制方式
5. **自动回充功能**：支持红外检测自动充电
6. **模块化设计**：各功能模块独立，易于维护和扩展
7. **代码审查完善**：有详细的代码审查报告
